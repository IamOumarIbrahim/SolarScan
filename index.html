OpenStreetMap Rooftop Solar Feasibility Engine

Automated Solar PV Reports from Building Footprints

An elegant neumorphic single-page engine extracting building polygons from OpenStreetMap to compute usable roof area, array DC capacity, and payback years.

Solar Engineering Engine

Automated Spatial Pipeline

🗺️

Footprint Extraction

Queries OSM Overpass API to extract building polygon vertices and computes exact area via the Shoelace formula.

📐

Setback Inset

Insets perimeter boundaries by fire-code safety distances (default 1.5m) and subtracts roof obstruction tags.

⚡

Array & Payback Sizing

Sizes DC array capacity, string inverter ratios (1.20 DC/AC), annual kWh yield, and simple financial payback years.
