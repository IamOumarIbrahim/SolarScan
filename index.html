Preliminary Feasibility Disclaimer

SolarScan output represents automated preliminary feasibility analysis based on public 2D OpenStreetMap building footprints. On-site structural engineering inspection, shading analysis, and local utility interconnection sign-off are required before final project procurement.

Verified First Command
