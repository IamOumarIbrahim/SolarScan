## Reporting a Vulnerability

We take the security of SolarScan seriously. If you believe you have discovered a security vulnerability in this project, please report it directly to the maintainers rather than creating a public issue.

### How to Report

Please report security issues by emailing the maintainer at `oumar@example.com` or creating a private security advisory on GitHub if enabled.

Please include the following details in your report:
- Type of issue (e.g. buffer overflow, credential leak, API injection)
- Step-by-step instructions to reproduce the issue
- Any proof-of-concept code or demonstration output
- Impact of the issue

### Vulnerability Response Process

1. **Acknowledgement**: We will acknowledge receipt of your report within 48 hours.
2. **Investigation**: We will investigate and confirm the report within 5 business days.
3. **Patching**: If validated, we will prepare a patch release promptly.
4. **Disclosure**: Once patched, a public advisory will be issued detailing the fix.
